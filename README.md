# Data Science Portfolio

A lightweight one-page Quarto portfolio for data science internship and job applications.

## Structure

- `_quarto.yml` configures the Quarto website and GitHub Pages output.
- `index.qmd` contains all one-page portfolio sections.
- `styles.css` contains the custom editorial styling.
- `assets/` is for your portrait, resume PDF, images, and project screenshots.
- `docs/` is generated by Quarto and used by GitHub Pages.

## Edit Content

Update the placeholder text in `index.qmd`:

- Replace placeholder email, LinkedIn, GitHub, project, and resume links.
- Add your real projects and project URLs.
- Add experience, education, and skills.
- Put your resume at `assets/resume.pdf`.
- Add a portrait or image to `assets/` and replace the portrait placeholder if desired.

Update `_quarto.yml`:

- Change `title`.
- Change `site-url` to your GitHub Pages URL.

## Preview Locally

Install Quarto from <https://quarto.org/docs/get-started/>.

```bash
quarto preview
```

Quarto will start a local preview server and refresh the site when you edit files.

## Render

```bash
quarto render
```

The rendered website will be written to `docs/`.

## Deploy With GitHub Pages

1. Push this repository to GitHub.
2. In GitHub, open the repository settings.
3. Go to **Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select your main branch and the `/docs` folder.
6. Run `quarto render`, commit the generated `docs/` folder, and push.

After GitHub Pages finishes building, your site will be available at:

```text
https://your-github-username.github.io/your-repo-name/
```

## Optional GitHub Action

For a more automated setup later, you can add a GitHub Actions workflow that installs Quarto, renders the site, and deploys the output. The current scaffold keeps deployment simple by using the `docs/` folder.

The one project I'd show you first

An LLM agent workflow that turns a bill of materials into a life-cycle carbon footprint report

14nodes alternating code and LLM
6.99g CO₂-e/kWh reproduced
55%of emissions traced to steel

Life-cycle assessment is slow, specialist work, and it starts over every time the product changes. I built a workflow that takes a turbine's bill of materials and returns a staged carbon footprint with ranked abatement measures. The platform wouldn't pass data between code nodes, so the LLM nodes double as typed couriers — each one told to reserialise its input as JSON without altering a number.
